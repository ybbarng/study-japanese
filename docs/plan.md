# 구축 계획

날짜를 정하지 않고 아래 순서대로 이어 가서 최대한 빨리 완성한다(docs/standing-rules.md "진행 방식"). 실제 학습은 2027-01-01부터.

끝 기준: 안드로이드 홈 화면에서 열리고 로그인해야 들어간다 / 가나 학습 전 과정이 돈다 / 일무따 60강·일문따 56과 오디오·글이 강·과 단위로 열리고 들은 기록이 남는다 / 잠금 화면 조작·화면 끈 채 재생이 실제 폰에서 된다 / 1월 1일 아침에 "0강"을 바로 누를 수 있다.

## 정한 기본값 (되돌리기 쉬운 것, 세션이 고름)
- 로그인: 사용자 한 명이라 암호 하나 + 서명한 httpOnly 쿠키. proxy가 모든 경로(오디오 포함)를 막는다.
- 기록 저장: 서버 SQLite. 세션은 `progress:pull`로 저장소 JSON을 받아 읽는다(앱이 서버에서 git에 쓰지 않게).
- 오디오: 서버 `media/`를 컨테이너에 읽기 전용으로 붙이고 앱 라우트가 로그인 확인 뒤 Range 요청까지 내준다.
- 몰입감: 화면 하나에 한 가지 일, 큰 글자·어두운 바탕, 재생 중 화면은 지금 문장만 크게. 배지·연속 일수는 가볍게.
