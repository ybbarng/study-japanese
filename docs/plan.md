# 구축 계획

날짜를 정하지 않고 아래 순서대로 이어 가서 최대한 빨리 완성한다(docs/standing-rules.md "진행 방식"). 실제 학습은 2027-01-01부터.

끝 기준: 안드로이드 홈 화면에서 열리고 로그인해야 들어간다 / 가나 학습 전 과정이 돈다 / 일무따 60강·일문따 56과 오디오·글이 강·과 단위로 열리고 들은 기록이 남는다 / 잠금 화면 조작·화면 끈 채 재생이 실제 폰에서 된다 / 1월 1일 아침에 "0강"을 바로 누를 수 있다.

## 그 뒤에 더한 것 (2026-11-23 사용자 요청)

| 순서 | 내용 | 상태 |
|---|---|---|
| A | PC 화면: 넓은 화면 두 칸, 자막 전체 목록, 키보드 단축키 | 다시 고치는 중(2026-11-24 학습자 점검: PC에서 "지금 하는 말" 카드가 숨겨지고 넓은 화면을 학습에 못 씀) |
| B | 공개 구조: 누구나 쓰고 기록·설정만 관리자, 출처별 공개 스위치·출처 표시 | 끝 |
| C | 강의 맥락 큐: 자막의 일본어 구간에 소책자 문장·해석·낱말 카드·그림(자막 데이터가 나온 뒤). 서버가 자막을 내줄 때 일본어 구간을 그 강 소책자 문장과 글자 편집 거리로 맞춰(`src/lib/context/match.ts`, 긍정·부정이 뒤집히거나 같은 한자가 없는 짝은 거름) 카드를 붙인다. 맞춘 비율은 `pnpm context:report`(일무따 강의 일본어 구간 82%, 일무따 전체 약 73%). 일문따는 소책자에 예문 글이 없어, 그 과 문법 예문(`-1`) 자막의 "일본어 → 뜻 → 같은 일본어" 되풀이에서 짝을 찾아 문장 후보로 쓴다(`src/lib/context/transcript-pairs.ts`, 두 일본어가 0.8 이상 닮고 긍정·부정이 같을 때만, 54개 파일에서 684쌍). 짝 파일은 따로 두지 않고 서버가 요청 때 자막으로 만든다. 받아 적은 글이라 카드에 "자막에서 받아 적은 글 — 교재와 다를 수 있음"을 작게 보인다. 일문따 문장 맞춤은 강의 일본어 구간 55%, 예문 53%. 낱말은 드릴 낱말·일무따 단어. 지금 줄의 "이 문장 반복"(L 키), 간격을 켜면 문장 끝에서 잠깐 쉼. 그림은 낱말 칩의 그림 문자로 시작했다: 세션이 지은 표 204개(`src/lib/context/emoji.ts`, 구체적인 낱말만), 화면에 뜨는 낱말 칩의 약 30%에 붙는다(`pnpm context:report`) | 다시 고치는 중(2026-11-24: 그림 30%는 요구에 못 미침, 짝짓지 못한 일본어 줄이 틀린 채 보임) |
| D | 노래 학습: 관리자가 노래 파일·가사를 직접 올림. **재생은 로그인한 사람만(고정)**, 가사 학습 화면은 공개(2026-11-23 사용자 결정). 노래마다 출처로 등록해 `/settings`에서 바로 닫을 수 있게. 사이트는 읽는 법·낱말 찾기(사전)·줄마다 박자 맞추기·구간 반복. 세션은 가사를 옮겨 적거나 통째로 번역하지 않고, 물으면 낱말·문법만 설명. 곡: 요네즈 켄시 「Lemon」·「感電」, 유우리 「ベテルギウス」, 요아소비 「祝福」 | 기능 끝·음원 서버에 있음, 가사는 사용자가 붙여 넣기 기다림 |
| E | 일문따 활용 드릴을 문장 속 빈칸으로(맥락 없는 활용표 반복을 줄임). 세션이 지은 문장 틀 47개(동사 25·형용사 12·명사 10)와 뜻 범주 15개(`src/lib/ilmunta/sentence-*.ts`). 시제·정중함·부정은 문장(昨日·先生、·あまり)이 알려 주고, 한국어 뜻은 눌러야 보인다. 강 범위는 기존 기술(curriculum)을 그대로 따른다. 동사 활용 전부와 형용사·명사 활용(さ 빼고)이 문장으로 나오고, 문형·경어·자타동사·있다·さ는 활용표 문제로 낸다. '활용표만 빠르게'로 바꿀 수 있다. 낱말마다 처음 나오는 과를 붙여(`pnpm ilmunta:word-lessons`, `word-lessons.ts`) 고른 범위까지 배운 낱말만 내고, 앞 문제와 같은 낱말은 피한다. 일무따에 나온 낱말은 처음부터 쓴다. 월말 범위 시험도 같은 규칙으로 그 달 마지막 과까지 배운 낱말만 내고 앞 문제 낱말을 피한다 | 끝 |

## 정한 기본값 (되돌리기 쉬운 것, 세션이 고름)
- 로그인: 사용자 한 명이라 암호 하나 + 서명한 httpOnly 쿠키. proxy가 모든 경로(오디오 포함)를 막는다.
- 기록 저장: 서버 SQLite. 세션은 `progress:pull`로 저장소 JSON을 받아 읽는다(앱이 서버에서 git에 쓰지 않게).
- 오디오: 서버 `media/`를 컨테이너에 읽기 전용으로 붙이고 앱 라우트가 로그인 확인 뒤 Range 요청까지 내준다.
- 몰입감: 화면 하나에 한 가지 일, 큰 글자·어두운 바탕, 재생 중 화면은 지금 문장만 크게. 배지·연속 일수는 가볍게.
