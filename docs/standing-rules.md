# 저장소 규칙

사용자가 정했거나 지적한 규칙을 모은다. 같은 주제는 새 줄 대신 고친다. 처음엔 작게 두고 쓰며 키운다.

## 진행 방식 (2026-11-23)
- 단계에 날짜를 정하지 않는다. `docs/plan.md` 순서대로 쉬지 않고 이어 가서 최대한 빨리 완성하고, 사용자가 전체를 써 보게 한다. 실제 학습은 2027-01부터.
- 차례를 끝낼 때도 다음 단계 서브에이전트나 백그라운드 일을 띄워 두어 일이 멈추지 않게 한다. 사용자 결정을 기다리는 일은 책상에 두고, 그것에 묶이지 않은 다음 단계를 먼저 한다.

## 저작권 (2026-11-23)
- 일무따·일문따 오디오, 소책자 PDF, xlsx는 산 자료다. 공개 저장소·공개 주소에 두지 않는다.
- 오디오·원본은 git에 넣지 않는다(`media/`, `textbook-src/`는 `.gitignore`, `scripts/guard-textbook-files.sh`가 pre-commit에서 막는다). 서버에 두고 로그인한 사람만 받는다.
- 교재에서 뽑은 글은 `content/textbook/`에 둔다. 저장소 공개 여부를 정하기 전까지 git 밖이다.
- 사이트 전체가 로그인 뒤에 있다. 로그인 없이 열리는 경로는 로그인 화면·PWA manifest·아이콘뿐이다.

## 커밋 나누기 (2026-11-23)
- 사이트 개발 커밋: 작은 의미 단위마다 바로 커밋한다. 메시지 머리는 `feat:`·`fix:` 같은 종류를 쓴다.
- 학습 기록 커밋: `study/` 아래(문장 쓰기·진도·점검)는 학습 세션이 끝날 때 묶어 커밋하고 메시지 머리는 `study:`로 한다.
- 한 커밋에 둘을 섞지 않는다.

## 학습 데이터
- 진도·들은 기록은 서버 DB에 쌓이고, `pnpm progress:pull`로 저장소 `study/progress/`의 JSON으로 받아 세션이 읽는다(계획·점검·버즈 인증).
- 1월 1일 전에 가나·듀오링고를 미리 시작하게 권하지 않는다(사용자가 새해에 시작하기로 함).

## 세션과 나누는 말
- 지금은 한국어 위주다. 일본어로 이야기하는 방식은 2분기나 3분기쯤 사용자와 정해 들인다.
- 일본어 오류 종류(조사 は/が/を/に, 활용·정중체, 자타동사, 한자 읽기, 악센트)는 쓰면서 정한다.
